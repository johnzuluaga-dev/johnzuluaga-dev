## 🚀 Proyectos destacados

### 💈 [BarberFlow – Automatización para Barberías](https://github.com/johnzuluaga-dev/automatizacion_para_barberias)
Sistema de automatización que gestiona citas, recordatorios y estadísticas para barberías, orquestado con **n8n**. Incluye:
- Agendamiento y cancelación automática de citas vía webhook
- Confirmaciones y recordatorios por WhatsApp
- Dashboard de estadísticas y reportes del negocio
- Stack: Vercel (frontend) · n8n (automatización) · Supabase (base de datos) · API de WhatsApp · OpenAI
